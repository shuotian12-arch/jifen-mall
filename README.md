# 积分商城系统

基于微信生态的积分会员系统，用户通过签到、邀请等行为累积积分，在积分商城兑换实物商品。

## 功能特性

### 用户端（小程序风格）
- 微信授权登录、个人信息查看
- 积分余额查看、积分明细记录
- 每日签到、邀请好友赚积分
- 商品浏览、积分兑换、核销码展示

### 管理员端（PC后台）
- 积分规则配置（新人/签到/邀请数值）
- 用户积分查询、手动增减积分
- 商品上下架、库存管理
- 兑换订单查询、核销码核销

## 技术栈

- Vue 3 + TypeScript
- Vue Router 路由管理
- Pinia 状态管理
- Tailwind CSS 样式
- Vite 构建工具

## 开发

```bash
npm install
npm run dev
```

访问 http://localhost:5174
